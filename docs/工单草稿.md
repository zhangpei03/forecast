## 阶段 3 · OE 部署(拿到上面凭据后)

部署单元:
- 镜像: hub.xiaojukeji.com/parkerzhang/forecast:v1
- 规格: 4C8G 起
- 持久卷: 挂到容器 /data
- 端口: 容器 80, 对接麒麟 router

环境变量(把 <尖括号> 换成真实值):

    DATABASE_URL=mysql+pymysql://forecast:<RDS密码>@<RDS_HOST>:3306/forecast_lab?charset=utf8mb4
    FORECAST_LAB_RUNTIME_DIR=/data
    MAX_CONCURRENT_TRAINING=3
    SSO_APP_ID=<工单1下发>
    SSO_APP_KEY=<工单1下发>
    SSO_COOKIE_SECRET=<部署时生成, 勿入仓>
    SSO_LOGIN_BASE=http://mis.diditaxi.com.cn/auth/sso/login
    CALLBACK_SCHEME=https

SSO_COOKIE_SECRET 用下方命令现生成(不要写进仓库/公开群):
这是密钥, 别发到公开群; 想换可重新跑:
python -c "from cryptography.fernet import Fernet;print(Fernet.generate_key().decode())"

不要设置: SSO_DEV_FAKE_USER / FORECAST_LAB_DEV_USER / SSO_CHECK_CODE_URL / SSO_CHECK_TICKET_URL
(留空会自动走默认 mis.diditaxi.com.cn)

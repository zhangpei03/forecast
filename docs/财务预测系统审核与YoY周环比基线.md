# 财务预测系统审核与 YoY 周环比基线

审核日期：2026-07-02  
样例：`专车实验_补充列_未来30天.xlsx`

## 审核结论

当前项目适合作为“预测算法评测 MVP”，但还不应直接定位成生产级财务预测系统。
核心缺口不是候选模型数量，而是协变量可用性治理、选模门槛、财务层级勾稽、预测区间校准和上线后监控。

### P0：投产前必须处理

1. **未来已知协变量缺少严格契约。** 页面会把候选协变量默认初始化为“已知未来”。若竞争成交率、补贴率、TSH 等在回测期使用实际值、在未来期却只能延续末值，回测会产生不可实现的信息优势。应按字段保存“可得时间、来源、未来覆盖率”，并阻断不满足未来可得性的实验。
2. **模型选择没有业务门槛。** 当前按聚合 WAPE 直接取第一名；“逐窗口跑赢基线的比例”只展示、不参与选择，也没有最小改善幅度或统计不确定性。建议要求候选模型同时满足：聚合 WAPE 改善、至少 2/3 窗口胜出、Bias 在阈值内，否则使用最佳基线。
3. **缺少财务层级一致性。** 城市、车型、区域、全国的预测独立产生，没有 bottom-up / top-down reconciliation，也没有 GMV、订单、补贴、收入间的勾稽检查。结果可能在单序列上准确、汇总后却不守恒。
4. **未来数据与训练数据边界曾混淆。** 默认 sum 聚合会把未来空目标变为 0，部分未来训练路径也会把预填行带入训练。本次已修复空目标保留、历史截止日、回测容量及主要训练入口，但仍建议为“实际区/未来区”建立显式数据状态字段。

### P1：影响预测可信度

1. `val_step_size` 已进入配置但未用于各模型切窗，所有窗口仍按 `prediction_length` 移动。
2. 只用全局 WAPE 会被上海、北京等大体量序列主导；应同时设置宏平均 WAPE、重点城市 WAPE、Bias 和金额误差护栏。
3. 基线的 P10/P90 等于点预测，外部模型的区间生成方法也不统一，Coverage 暂不能用于跨模型公平比较。应做滚动残差或 conformal calibration。
4. 增长率、月份事件和情景调整在模型输出后统一乘数化，若参数根据验证期结果调过，会形成回看偏差；也无法区分“模型能力”和“人工调整贡献”。
5. 缺少异常值、结构突变、口径变更和延迟入账的专门处理；只有缺失、重复、长度等基础检查。
6. 当前是全局选一个模型预测全部序列，没有按城市/车型做分层选择或小样本收缩。

### P2：生产运营能力

1. 缺少预测版本冻结、审批、人工覆盖记录、原因码和完整审计日志。
2. 缺少实际回填后的自动监控：WAPE/Bias 漂移、协变量漂移、模型失效和重训策略。
3. 缺少单位、币种、含税口径、会计期间和数据来源的强校验。
4. 大规模运行仍以单机逐序列训练为主，缺少资源估算、任务重试幂等和模型缓存治理。

## 新增基线：YoY Weekday WoW / DoD

仅对日频数据启用，`YoY Weekday WoW` 步骤如下：

1. 目标日先减一年得到自然日同比锚点，再移动到最近的同星期日。例如 2026-07-02（周四）对齐 2025-07-03（周四）。
2. 计算去年同星期日的周环比：`2025-07-03 / 2025-06-26`。
3. 用该周环比乘今年前一周同星期日的实际或预测值：`2026-06-25 × 去年周环比`，得到 2026-07-02。
4. 预测超过 7 天后，上一周预测会成为下一周基数，实现逐周滚动。
5. 若原始周环比较同月前后参照中位数偏离超过 20%，使用前后最近的周环比中位数；同月样本不足时扩展至前后 4 周。
6. 分母为 0、历史不足或比例无效时，依次退化到稳健参照比例和 1.0。

`YoY Weekday DoD` 与上述逻辑相近，但使用日环比：

1. 目标日同样先对齐到去年自然日期附近的同星期日。
2. 计算去年对齐日的日环比：`(去年对齐日 - 去年对齐日前一天) / 去年对齐日前一天`。
3. 用 `今年前一天实际或预测值 × (1 + 去年日环比)` 得到目标日预测。
4. 若原始日环比较前后 4 周同星期日的日环比中位数偏离超过 20%，使用该中位数替代。
5. 分母为 0、历史不足或比例无效时，依次退化到稳健参照日环比和 0.0。

## 样例验证

- 历史实际：2024-01-01 至 2026-06-24。
- 未来协变量：2026-06-25 至 2026-07-24，共 30 天。
- 序列：107 条（车型 × 城市），未来输出 3,210 行，无空预测、无负预测。
- 3 个 30 天窗口聚合 WAPE：Seasonal Naive 9.34%，新增基线 15.20%。因此本样例中新增基线不会被误选为最佳模型，但会作为可解释业务基线持续参与后续实验。

该结果说明基线逻辑已正确接入，不代表参数已经最优。20% 异常阈值和前后搜索范围应在更多月份、春节和极端天气样本上单独回测后再冻结。

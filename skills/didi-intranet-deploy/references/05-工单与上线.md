# 阶段4 - 工单与上线 (人工提单部分)

代码和镜像就绪后, 剩下是只能由人在公司系统操作的部分。
用 `scripts/gen_ticket_draft.py` 一键生成填好值的工单草稿 + 环境变量 + Fernet 密钥。

## 四个工单 (并行提, 各 1~3 工作日)

1. SSO 接入(BPM `sso_upm_app_add_v3`)
   https://bpm.didichuxing.com/process/form/bykey/sso_upm_app_add_v3?tenantId=SSO
   回调地址填 `https://<域名>/sso/callback`; 审批后邮件下发 APP_ID/APP_KEY。

2. 内网域名(BPM)
   https://bpm.didichuxing.com/process/form/bykey/information_security_domain_insert?tenantId=BPM
   业务线选麒麟; IP 解析到麒麟 router; 域名必须与工单1回调一致。

3. 安全评估(SDL): https://sdl.xiaojukeji.com/sdl/dorado

4. MySQL RDS(数据库平台): 库名 + 账号密码; 机房与 OE 同机房。

## 生成密钥
```
python -c "from cryptography.fernet import Fernet;print(Fernet.generate_key().decode())"
```
作为 SSO_COOKIE_SECRET, 只配在 OE 环境变量, 不入仓、不发公开群。

## OE 部署
- 镜像: hub.xiaojukeji.com/<user>/<app>:v1
- 规格: 按负载, 有本地训练/计算的 >= 4C8G
- 持久卷挂到 /data (必须, 否则容器重启用户数据全丢)
- 容器 80, 对接麒麟 router(HTTPS 通常 router 终止, 容器内 nginx 收 http, CALLBACK_SCHEME=https)

## 环境变量清单
```
DATABASE_URL=mysql+pymysql://<user>:<pass>@<host>:3306/<db>?charset=utf8mb4
APP_RUNTIME_DIR=/data
SSO_APP_ID=<工单1下发>
SSO_APP_KEY=<工单1下发>
SSO_COOKIE_SECRET=<生成的 Fernet key>
SSO_LOGIN_BASE=http://mis.diditaxi.com.cn/auth/sso/login
CALLBACK_SCHEME=https
```
生产不要设: SSO_DEV_FAKE_USER / *_DEV_USER / SSO_CHECK_CODE_URL / SSO_CHECK_TICKET_URL
(留空走默认 mis.diditaxi.com.cn)。
